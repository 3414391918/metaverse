# 视频自定义风格预设

每次依据小说正文、首尾帧和本书已确定的插画视觉语言，现场填写一份预设。明确区分“已有事实”与“为了视频统一而作的设计选择”。不机械套用写实、赛璐璐或游戏 CG 等固定风格；人物和场景资产优先于风格修饰。

```text
风格名称：[从本书确定]
定义：[一句话说明画面媒介、质感与叙事气质]
核心色调：[主色、辅助色、禁止色；说明与首尾帧的关系]
视觉权重：[角色与关键动作 X% + 场景空间 Y% + 光影/特效 Z%，合计 100%；按本段重心决定]
必须做：
- [关键视觉特征 1]
- [关键视觉特征 2]
- [关键视觉特征 3]
禁止做：
- [会使角色、服装或场景失真的偏差 1]
- [会破坏首尾帧或情绪的偏差 2]
- [噪声、文字或廉价特效等偏差 3]
典型应用：[本段剧情中的镜头用途]
依据：[正文、现有插图或两帧中支持这个选择的具体证据]
```

这是根据 [video-prompt-builder 的自定义预设结构](https://github.com/BH2-4/video-prompt-builder/blob/main/references/style-presets.md) 调整的小说视频版本。原项目由 BH2-4 以 MIT 许可发布；许可文本见 [上游 LICENSE](https://github.com/BH2-4/video-prompt-builder/blob/main/LICENSE)。
