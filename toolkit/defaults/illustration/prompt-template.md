# 连续插图的逐张物料模板

本工具只交付**插图设计物料**，不生成、审核或插入图片。先读剧情并由用户确定本轮主要人物，再在内部按时间顺序规划镜头。最终逐张交付；**每张提示词都必须独立可用**，只看这一张的参考图和提示词也能知道人物、衣装、场景和动作。

## 内部规划，不写进生图提示词

- 依据正文确定每张插图的插入位置、这一瞬间可见的人物与动作、表情、服装、伤势、道具、空间和光源。跨镜头的状态继承在内部核对，再改写成每张提示词中的**具体可见状态**。
- 每张只呈现一个时间点。按剧情需要使用特写、近景、中景、远景和不同机位；不把起手、命中、结果等先后动作拼在同一画面。新场景或主要光源显著改变且没有可用纯场景图时，先设计一张无人的场景建立图。
- 只选用已入本书正文的无人纯场景图和当前形象的原始角色资产图作图片输入。每个出镜的主要人物分别提供脸部特写、全身图；非主要角色只提供全身图。缺失图片必须标为缺项，不编造路径。

以上人物衣装与场景文字只示范输出形式，**不能作为小说设定复用**。实际交付时，先核对正文与角色资产，再写出与本张画面相符的具体衣装和环境；示例路径必须替换为**真实存在且可读取的绝对路径**。预览必须是真正的 Markdown 图片，不能放进代码块，也不能只写图片路径；图片下方另以文本代码块展示同一绝对路径，便于复制。元宇宙内嵌 Harness 会话会显示本地图片预览，用户可右键图片选择“复制图片”。路径含空格时使用 `![名称](<绝对路径>)`。尚未存在的图片只列为缺项，不输出伪预览或伪路径。

## 生图提示词的硬规则

1. **第一段先逐张解释所有参考图片是什么、分别固定哪些可见特征**，例如“慕星离脸部特写”“慕星离全身图”“夜晚浅洞纯场景图”；不能只写编号、文件名或“参考以上图片”。提示词中的参考图与该张物料展示的图片一一对应，不遗漏、不加入额外图片。
2. **随后直接描述完整画面**。把连续性转化为具体画面事实，例如当前衣装、伤势、站位、情绪与环境状态；不依赖其他镜头的文字或图片。
3. 提示词中不写“剧情锚点与唯一事件”“与上一镜的连续性”“上一镜”“延续前一张”“第 N 张”等流程字段或相对引用；不要求生图模型推断前后剧情。章节、原文锚点、镜头编号和设计理由只放在物料说明里，**不放进生图提示词**。
4. 纯场景建立图也独立描述空间、陈设、时段、天气、光源、机位和风格，明确画面无人；有适用的现成纯场景图时不重复规划。战斗插图写清此刻各人的实际姿势、出力方式与特效可见的起点、路径和落点，避免动作阶段混画。画幅按画面需要建议，不固定尺寸。

## 最终结果顺序

1. 一行说明小说、目标章节或片段、风格，以及用户确认的主要人物名单。
2. 按剧情顺序逐张输出上述**完整物料**：正文定位、该张全部参考图的预览与绝对路径、该张可单独使用的完整生图提示词。不要用全局图片清单代替逐张展示。
3. 最后列出缺失的无人场景图和必需角色资产，由用户后续生成、验证和插入。本工具不规定平台图片上传数量上限，也不删减参考图或制作拼版。
