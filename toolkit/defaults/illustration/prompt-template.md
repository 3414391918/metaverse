# 连续小说插图提示词模板

先通读目标剧情，规划一组按时间推进的镜头，再为每张插图单独填写一份提示词。整组镜头共同讲清剧情起因、推进和结果；每张图只固定一个瞬间。方括号内填写从本书和用户要求取得的事实；没有证据时删去该字段，不猜测。把所选角色资产图、场景旧图以及可用的前一张插图作为生图工具的图片输入，与文字提示词一起提交。

## 整组镜头计划

生成第一张前，先建立一张镜头表；用户指定数量时按指定数量安排，否则按有画面价值的剧情节拍决定张数，不预设固定张数。

| 序号 | 正文锚点与插入段落 | 此帧唯一可见的动作或情绪 | 与上一帧的变化 | 必须延续的人物、道具、场景状态 | 参考图 |
| --- | --- | --- | --- | --- | --- |
| 1…N | [章节与准确段落] | [一个瞬间] | [首次建立／由上一帧变化] | [形象、站位、伤势、衣物、道具、光源、场景损坏] | [角色资产、旧场景图、上一帧] |

人物脸部、发型、服装和场景结构的固定信息在整组中共享；姿态、表情、站位、道具状态、战斗特效与环境变化按正文逐帧更新。不要把同一动作的起手、命中和结果并入一张图，也不要让后一张无故恢复前一张已改变的状态。场景切换时建立新场景锚点，继续保留角色已经发生的变化。

每一帧写生图提示词前，用正文和镜头计划整理一张简短的场景卡：

| 字段 | 要确定的内容 |
| --- | --- |
| 剧情锚点 | 章节、准确段落、当前发生的一个动作或情绪转折；下一动作仅用于选镜，不进入画面 |
| 人物锚点 | 每个出镜角色的 ID、当前形象 ID、角色资产图及该时刻的姿态、表情 |
| 场景锚点 | 场景名称、前文插图及必须保持的布局、陈设和道具；只列这次发生变化的部分 |
| 镜头目标 | 读者看图后应该立刻明白的事件、人物关系或情绪 |
| 风格锚点 | 用户指定风格或本书已有插图的线条、材质、色彩和光影 |
| 连续性锚点 | 上一帧图片与当前延续状态；本帧新增的剧情变化及下一帧需要继承的结果 |

场景卡是 Agent 的取材记录，不需整张塞进生图模型。真正提交给生图工具的提示词如下，先说画面主体和动作，再说不变的视觉锚点与镜头。

```text
请生成本组连续小说插图的第 [序号]／[总数] 张高质量静态图片。它承接上一张，并准确表现当前剧情瞬间。

剧情瞬间：[章节、段落、发生时刻；这一帧中可见的单一动作或情绪转折]
前一帧与状态继承：[上一张图片编号或“首帧”；延续的角色位置、朝向、衣物、伤势、道具、场景与光线]
本帧变化：[正文在上一帧与本帧之间明确发生的变化；没有依据的变化不添加]
画面要表达：[读者应立刻看懂的事件、关系或情绪]
画面主体：[主要人物或关键物件、此刻的姿态、视线、手与物件的接触关系]
人物一致性：[逐个写明角色姓名、所选形象、脸部身材、发型服装；对应哪几张角色资产参考图]
场景一致性：[地点名称、固定空间布局、建筑和陈设；对应哪张前文场景插图；本次唯一允许改变的环境状态]
构图与视角：[主体位置、人物和道具的前后左右关系、景别、机位、焦点与留白；由内容决定画幅方向和比例]
风格：[用户指定风格，或已有插图的线条、材质、配色和光影语言]
光色与气氛：[该时刻有依据的光源、主色和情绪]
战斗特效（仅在本画面确有战斗时）：[这一动作对应的法术形态、运动方向、强度与环境反应；特效充足，关键人物和动作仍清楚]

画面只呈现一个确定的瞬间。保持角色脸部、服装和场景结构与角色资产、前文场景图及本组上一帧一致；仅改变本帧剧情要求改变的状态。主体清晰，画面层次分明，细节有据可依。不要把先后发生的动作拼贴成一张图，不要多格分镜、重复肢体、无关人物、无关装饰、文字、水印或过多随机光点与噪声。保留构图需要的完整主体，不为预设尺寸裁切重要内容。
```

生图模型支持多张参考图时，给每张图编号并说明职责，例如“图 1 与图 2 固定慕星离的脸和当前服装；图 3 固定欲仙楼的楼梯与石台布局；图 4 是上一帧，延续站位和灯光；本帧只改变正文已发生的动作”。参考图之间有冲突时，以当前剧情适用的角色形象、已确认设定和用户明确要求为准。提示词只描述最终可见画面，不把 Agent 的工具调用步骤写进生图请求。生成一张后，将其实际输出路径加入下一帧的参考图清单，再继续生成；整组图片按镜头表顺序插入对应段落。
