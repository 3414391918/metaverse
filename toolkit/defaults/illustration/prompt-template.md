# 连续小说插图提示词模板

先通读目标剧情，规划一组按时间推进的镜头，再为每张插图单独填写一份提示词。整组镜头共同讲清剧情起因、推进和结果；每张图只固定一个瞬间。方括号内填写从本书和用户要求取得的事实；没有证据时删去该字段，不猜测。把所选角色资产图、场景旧图以及可用的前一张插图作为生图工具的图片输入，与文字提示词一起提交。角色资产图要分别承担面部与当前服装参考，不能只传脸部特写来生成有服装的画面。

## 整组镜头计划

生成第一张前，先建立一张镜头表；用户指定数量时按指定数量安排，否则按有画面价值的剧情节拍决定张数，不预设固定张数。

| 序号 | 正文锚点与插入段落 | 此帧唯一可见的关键动作或表情 | 相对上一帧的时间与情绪变化 | 景别、机位及选用理由 | 必须延续的人物、道具、场景状态 | 当前形象 ID 与判定依据 | 参考图 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1…N | [章节与准确段落] | [一个瞬间及有依据的面部、视线或手势细节] | [首次建立／经过的时间、动作及情绪变化] | [特写／近景／中景／必要的远景；视角为何服务本帧] | [形象、站位、伤势、衣物、道具、光源、场景损坏] | [每个角色的形象 ID；本段或最近一次明确换装的正文位置] | [每个角色的脸部特写与当前形象服装资产、旧场景图、上一帧；注明各图实际覆盖部位] |

人物脸部、发型、服装和场景结构的固定信息在整组中共享；姿态、表情、站位、道具状态、战斗特效与环境变化按正文逐帧更新。围绕关键动作和情绪转折选镜：特写捕捉面部或手部细节，近景呈现反应和动作，中景说明人物关系与动作方向；需要交代空间时再用远景。可用不同机位、不同时间点的相邻插图呈现情绪递进，但每帧只画该时刻的状态，机位切换后仍须让人物站位与场景方位可辨。不要机械凑齐各种景别，不要把同一动作的起手、命中和结果并入一张图，也不要让后一张无故恢复前一张已改变的状态。场景切换时建立新场景锚点，继续保留角色已经发生的变化。

每一帧写生图提示词前，用正文和镜头计划整理一张简短的场景卡：

| 字段 | 要确定的内容 |
| --- | --- |
| 剧情锚点 | 章节、准确段落、当前发生的一个动作或情绪转折；下一动作仅用于选镜，不进入画面 |
| 人物锚点 | 每个出镜角色的 ID、当前形象 ID、判定该形象的正文位置、脸部特写参考图（若有）及该时刻的姿态、表情；其他形象的脸部特写只能用来固定五官和脸型 |
| 服装锚点 | 当前形象 ID 的定妆参考图、实际覆盖的全身／上半身／下半身部位，以及形象文本中的衣服版型、层次、颜色、纹样和配饰；缺少的部位只据文本描述，不用其他形象的服装补全 |
| 场景锚点 | 场景名称、前文插图及必须保持的布局、陈设和道具；只列这次发生变化的部分 |
| 镜头目标 | 读者看图后应该立刻明白的事件、人物关系或情绪；本帧捕捉的关键动作和具体表情 |
| 景别与机位 | 特写、近景、中景或必要的远景；观察角度、焦点，以及相对上一帧为何切换时间点或机位 |
| 风格锚点 | 用户指定风格或本书已有插图的线条、材质、色彩和光影 |
| 连续性锚点 | 上一帧图片与当前延续状态；本帧新增的剧情变化及下一帧需要继承的结果 |

场景卡是 Agent 的取材记录，不需整张塞进生图模型。真正提交给生图工具的提示词如下，先说画面主体和动作，再说不变的视觉锚点与镜头。

```text
请生成本组连续小说插图的第 [序号]／[总数] 张高质量静态图片。它承接上一张，并准确表现当前剧情瞬间。

剧情瞬间：[章节、段落、发生时刻；这一帧中可见的单一动作或情绪转折]
前一帧与状态继承：[上一张图片编号或“首帧”；延续的角色位置、朝向、衣物、伤势、道具、场景与光线]
本帧变化：[正文在上一帧与本帧之间明确发生的变化；没有依据的变化不添加]
画面要表达：[读者应立刻看懂的事件、关系或情绪]
画面主体：[主要人物或关键物件、此刻的姿态、视线、手与物件的接触关系；关键动作和有正文依据的眉眼、嘴角或手势细节]
情绪递进：[前一帧到本帧发生了什么情绪变化；画面只呈现本帧可见的表情和身体反应]
人物面部：[逐个写明角色姓名；若有脸部特写，列出本帧的图片编号，只用它固定五官和脸型，不用它推断整套服装]
当前形象与服装：[逐个写明当前形象 ID 与名称、发型、衣服版型、层次、颜色、纹样及配饰；列出同一形象的定妆图编号及每张实际覆盖的全身／上半身／下半身部位；只让它决定画面中可见的对应服装，不把局部图称为全身图；无服装图片时仅据形象文本描述]
场景一致性：[地点名称、固定空间布局、建筑和陈设；对应哪张前文场景插图；本次唯一允许改变的环境状态]
构图与视角：[主体位置、人物和道具的前后左右关系；按本帧叙事重点选择特写、近景、中景或必要的远景，说明机位、焦点与留白；由内容决定画幅方向和比例]
风格：[用户指定风格，或已有插图的线条、材质、配色和光影语言]
光色与气氛：[该时刻有依据的光源、主色和情绪]
战斗特效（仅在本画面确有战斗时）：[这一动作对应的法术形态、运动方向、强度与环境反应；特效充足，关键人物和动作仍清楚]

画面只呈现一个确定的瞬间。保持角色脸部、服装和场景结构与角色资产、前文场景图及本组上一帧一致；仅改变本帧剧情要求改变的状态。主体清晰，画面层次分明，细节有据可依。不要把先后发生的动作拼贴成一张图，不要多格分镜、重复肢体、无关人物、无关装饰、文字、水印或过多随机光点与噪声。保留构图需要的完整主体，不为预设尺寸裁切重要内容。
```

生图模型支持多张参考图时，给每张图编号并说明角色、形象 ID、实际覆盖部位与职责，例如“图 1 是慕星离的脸部特写，只固定五官和脸型；图 2 是慕星离当前形象的上半身定妆，只固定画面可见的衣领、袖型和上半身配饰；图 3 固定欲仙楼的楼梯与石台布局；图 4 是上一帧，延续站位和灯光”。生成前确认没有将下半身或其他局部资产误写成全身定妆，也没有漏传当前形象的服装参考。只要角色资产有脸部特写，该角色出镜的每一帧都需重新传入特写图；当前形象有服装资产时也每帧传入，上一帧不能代替这些角色锚点。**只要生成或编辑后的图中有慕星离，每次文生图、后续生图或图片编辑都必须重新传入她当前形象 ID 对应的脸部特写；即使只修改背景、服装或特效也一样。缺少该特写或接口无法传图时停止该次调用，不能改用纯文字、上一帧或其他形象的特写。**参考图之间有冲突时，以当前剧情适用的角色形象、已确认设定和用户明确要求为准。提示词只描述最终可见画面，不把 Agent 的工具调用步骤写进生图请求。生成一张后，将其实际输出路径加入下一帧的参考图清单，再继续生成；整组图片按镜头表顺序插入对应段落。
