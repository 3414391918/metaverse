# 首尾帧视频脚本交付模板

每次只交付用户选定的一对首尾帧。两张图片都必须实际查看，并已核对为小说正文插图。首帧和尾帧各自必须展示 Markdown 预览与可复制的绝对路径，并明确标记为 image 1 和 image 2，不能合并为一份模糊的参考图清单。

```text
本次范围：[书名／卷／章／正文起止锚点]
正文依据：[首帧前因 → 中间动作 → 尾帧结果的简要因果链]
建议时长：[N 秒及依据]
复杂度：[L1／L2／L3及理由]
一致性结论：[可直接过渡／需要明确转场／不建议直接生成及原因]

首帧（image 1）：
![首帧预览](首帧绝对路径)
绝对路径：[首帧绝对路径]
画面说明：[人物、形象、姿态、站位、场景、光线、构图和动作起点]
正文位置：[图片引用附近的正文锚点]

尾帧（image 2）：
![尾帧预览](尾帧绝对路径)
绝对路径：[尾帧绝对路径]
画面说明：[人物、形象、姿态、站位、场景、光线、构图和动作落点]
正文位置：[图片引用附近的正文锚点]

人物设计依据：
- [人物]：[appearanceId／当前形象名称／与两帧可见外观的关系]
- ……
可见差异与处理：[服装、伤势、光线、机位等差异如何在中间过程解释；无则写“无”]

视频生成提示词：
[按下方骨架填写，可整段复制]

上传要求：在视频生成平台实际上传 image 1 为首帧、image 2 为尾帧；本地路径文本不能代替图片上传。
风险或待确认项：[无则写“无”]
```

## 视频生成提示词骨架

```text
参考图说明：image 1 是首帧，展示[不依赖外部说明，完整描述首帧中的人物、形象、服装、姿态、站位、场景、光线与构图]；image 2 是尾帧，展示[不依赖外部说明，完整描述尾帧中的人物、形象、服装、姿态、站位、场景、光线与构图]。视频必须从 image 1 的可见状态准确开始，最后准确停在 image 2 的可见状态；不得交换顺序，不得在尾帧之后继续发生新动作。

正文情节：[完整概述这两帧对应的前因、两帧之间发生的事件和尾帧结果；只使用正文已确认事实]。
人物设定：[逐个说明出镜人物的身份、当前形象、五官、发型、服装、伤势、能力或动作限制，以及这些设定在本段中的可见体现]。
目标时长：[N 秒]。视觉风格：[根据正文和两帧实际画面填写]。叙事核心：[有正文依据的最短因果链]。

人物与场景锚点：[逐个写人物站位和朝向；写场景结构、时间、光源、天气、关键道具。以首尾帧可见事实和人物当前形象为准]。

镜头与动作：
[0s–Xs] [从首帧的静态状态开始，写景别、机位、运镜、动作启动、表情和同步声音]。
[Xs–Ys] [写动作如何连续发展，角色与道具的空间关系，必要的对话及光影／天气／伤势变化]。
[Ys–Ns] [动作收束并逐步对齐尾帧的构图、站位、表情与环境，最后一刻准确停在 image 2]。

连续性要求：[两帧差异的可见过渡；轴线、重心、道具、服装、伤势和光线不能无故跳变]。
音频：[环境底噪、动作拟音、必要配乐及时间点]。
对白：[只写正文原话、说话者和时间点；没有则写“无对白”]。

严格避免：人物换脸、无依据换装或伤势消失、人物数量变化、场景漂移、跳轴、瞬移、动作或特效瞬间完成、首尾帧顺序颠倒、无法解释的时间或地点跳跃、尾帧之后继续动作、无关文字、水印和旁白。

独立使用要求：本提示词已经包含理解视频所需的正文情节、人物设定、首帧状态、尾帧状态和完整变化过程；不得写“如上图”“上述人物”“上一段”“参考前文”或依赖本提示词之外信息的指代。本地绝对路径只在交付清单中展示，不写入本提示词来代替图像内容。
```
